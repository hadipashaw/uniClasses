# uniClasses

**uniClasses** یک اپلیکیشن اندرویدی (Kotlin) برای مدیریت برنامه‌ی کلاسی دانشگاه و یادآوری (آلارم) کلاس‌هاست. با این اپ می‌تونی جدول کلاس‌هات رو وارد کنی و قبل از شروع هر کلاس، نوتیفیکیشن/آلارم دریافت کنی تا هیچ‌وقت کلاستو از دست ندی.

## ✨ امکانات

- ثبت و مدیریت برنامه‌ی هفتگی کلاس‌ها (نام درس، روز، ساعت شروع و پایان، مکان/استاد)
- تنظیم آلارم خودکار قبل از شروع هر کلاس با استفاده از `AlarmManager`
- نمایش کلاس‌های امروز/هفته در یک رابط کاربری ساده
- ذخیره‌سازی محلی اطلاعات روی دستگاه (بدون نیاز به سرور)

## 🛠️ تکنولوژی‌ها

- **زبان:** Kotlin
- **پلتفرم:** Android

1. اپ را از بخش Releases دانلود و نصب کن (یا از سورس بیلد بگیر).
2. اپ را اجرا کن.

4. مجوز آلارم/نوتیفیکیشن را به اپ بده.
5. آلارم‌ها به‌صورت خودکار قبل از هر کلاس فعال می‌شوند.
