# uniClasses

**uniClasses** ابزاری برای مدیریت برنامه‌ی کلاسی دانشگاه و یادآوری (آلارم) کلاس‌هاست. با این پروژه می‌تونی جدول کلاس‌هات رو وارد کنی و قبل از شروع هر کلاس، یادآوری/آلارم دریافت کنی تا هیچ‌وقت کلاستو از دست ندی.

## ✨ امکانات

- ثبت و مدیریت برنامه‌ی هفتگی کلاس‌ها (نام درس، روز، ساعت شروع و پایان، مکان/استاد)
- تنظیم آلارم خودکار قبل از شروع هر کلاس
- نمایش کلاس‌های امروز/هفته
- ذخیره‌سازی محلی اطلاعات (بدون نیاز به سرور)

## 📖 نحوه‌ی استفاده

1. برنامه را اجرا کن.
2. کلاس‌های خودت را با مشخصات (نام درس، روز، ساعت) اضافه کن.
3. آلارم‌ها به‌صورت خودکار قبل از هر کلاس فعال می‌شوند.
